# 360度智能行车辅助系统项目实战计划书

## 1. 项目介绍与目标

本项目旨在开发一款基于Linux环境、结合机器视觉与网络通信技术的智能行车辅助系统。系统通过车载摄像头采集车辆四周影像，实现行车、倒车、鸟瞰等多种模式的实时监控，具备车辆识别、红绿灯检测及行车记录功能，并通过TCP/IP网络将关键数据上传至服务器 。

该项目采用 **C/S (客户端/服务器)** 架构，重点考察 Linux 高并发服务器开发、Qt 界面编程、OpenCV 图像处理及数据库操作能力 。

## 3. 系统架构设计

系统采用 **前置服务器 + 后置服务器** 的双层架构，通过共享内存与消息队列进行进程间通信 (IPC)，以实现高并发处理能力。

### 3.1 总体架构流

1. 
**客户端** -> 发送请求 -> **前置服务器** 


2. 
**前置服务器** (Epoll监听) -> 线程池处理 -> **写共享内存** -> **发消息队列** -> **后置服务器** 


3. 
**后置服务器** -> 收消息队列 -> 线程池处理 -> **读共享内存** -> **MySQL数据库操作** -> **写共享内存** -> **发消息队列** -> **前置服务器** 


4. 
**前置服务器** -> 收消息队列 -> 读共享内存 -> **返回结果给客户端** 



### 3.2 模块技术栈

* 
**前置服务器**: 面向对象Socket封装、Epoll IO复用、线程池、共享内存+信号量+消息队列 。


* 
**后置服务器**: 共享内存+信号量+消息队列、线程池、MySQL数据库封装类 。

## 4. 客户端功能需求

客户端采用 Qt 堆栈窗口 (QStackedWidget) 布局，登录成功后进入主界面 。

### 4.1 用户与系统模块

1. 
**开机动画**: 使用 OpenCV 播放视频作为开机动画 。


2. **系统设置**:
* 配置服务器IP地址和端口号，点击保存后才能连接网络 。


* 
**配置文件**: 本地保存为 `.txt` 文件。首次运行需手动输入，后续运行从文件读取 。




3. **注册/登录**:
* 密码传输: 服务器数据库中保存 **MD5加密** 后的密码 。


* 验证码: 注册界面验证码需对接短信平台（后续课程讲解） 。





### 4.2 视频监控业务 (核心)

所有模式最终提交版本均需为**摄像头实时业务** 。

1. **行车模式**:
* 实时展示摄像头画面。
* 
**智能识别**: 包含红绿灯检测、车辆检测 (使用OpenCV级联分类器) 。


* 
**自动录制**: 每隔 10秒 录制 300帧 视频，保存为 `.avi` 文件 。




2. **倒车模式**:
* 展示倒车影像，需包含辅助线绘制（安全区/警告区/危险区） 。


* 同样执行每10秒录制300帧的逻辑 。




3. **鸟瞰模式**:
* 通过图像拼接技术（透视变换）展示车身周围全景图 。


* 同样执行录制逻辑 。





### 4.3 记录与回放

1. 
**视频列表**: 分页展示本地录制的视频数据（需支持滚动条、加载更多） 。


* 文件保存格式: 视频 `.avi` + 首帧预览图 `.jpg` 。




2. 
**特征图片列表**: 分页展示截图上传的图片记录 。


3. **截图上传业务**:
* 
**自动上传**: 行车模式下，每隔 15秒 自动截取完整一帧并上传 。


* 
**手动上传**: 在视频播放界面，点击按钮截图并上传 。


* 
**文件传输机制**: 图片文件 (`.jpg`) 需**拆分**后逐个碎片上传，服务器接收并拼合，实现双端备份 。

## 5. 服务器功能需求

### 5.1 业务处理

* 
**接入管理**: 响应客户端连接，管理客户端信息，超时未登录自动断开 。


* 
**并发处理**: 利用 Epoll 和线程池处理高并发业务请求 。


* 
**数据存储**: 接收客户端上传的截图文件碎片并组装保存；处理登录验证及历史记录查询 。



### 5.2 日志系统

1. 
**实时日志 (前置服务器)**: 在控制台中打印客户端的请求信息 。


2. 
**全部日志 (后置服务器)**: 记录所有用户操作（谁、时间、操作内容）到数据库日志表，并支持导出为 `.txt` 日志文件 。



---

## 6. 关键技术实现细节

### 6.1 客户端线程设计

为避免界面卡顿，需严格遵循多线程设计规范 ：

1. **网络读线程** (单例类)
2. **网络写线程** (单例类)
3. **视频文件播放线程**
4. **摄像头播放线程** (单例类)
5. **拆分文件线程** (用于图片碎片上传)
6. **心跳线程** (维持长连接)
7. **线程池 (QThreadPool)** (处理耗时任务)

### 6.2 通信协议

* 
**协议制定**: 组内需统一通信协议，定义请求头、请求体、返回头、返回体结构体 。


* **数据包结构参考**:
* 包头 (0x040x04) + 接入层数据 + 业务层数据 + 校验码 + 包尾 。


* 支持变长数据包传输 。





### 6.3 数据库设计

* 
**表结构**: 组内统一设计，需包含用户表、视频记录表、日志表等 。


* 
**操作规范**: 使用 SQL 语句操作，禁止完全依赖图形化工具，操作前需备份 。
